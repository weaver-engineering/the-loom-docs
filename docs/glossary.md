# Glossary Of Terms
| Term                 | Description                                                                                                        |
| -------------------- | ------------------------------------------------------------------------------------------------------------------ |
| Architect            | The user persona representing the human responsible for delivering a feature through afentic software engineering. |
| Architects Assistant | The user persona representing the AI agent acting as a general assistant through the implementation of a Feature.  |
| Feature              | A set of behaviors required by a system in a project                                                               |
